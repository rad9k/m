star is one hub with N edges. three-children adds three edges under each of those targets, each to its own vertex, so the copied subgraph has 4N edges.

star copy(50000) / copy(10000) = 2.19. three-children copy(50000) / copy(10000) = 4.43. At 50000 top edges, three-children / star = 5.52. From 10000 to 50000 top edges, linear growth is about 5 and quadratic growth is about 25. At the same top-edge count, three-children has 4 times as many edges, so a linear cost is about 4 times star and a cost quadratic in the edge count is about 16 times star.
