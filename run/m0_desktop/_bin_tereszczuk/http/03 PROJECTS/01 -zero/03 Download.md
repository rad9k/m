## Release

The -zero is using .NET 10. The OS requirements are:
	- **console** version works on: 
		- Windows _(x86, x64, Arm64)_
		- macOS (x64, Arm64)
		- Linux (x64, Arm64, Arm32)
	- **desktop** version requiers Windows _(x86, x64, Arm64)_
	
.NET 10 Runtime is needed to run -zero. You can download it **[https://dotnet.microsoft.com/en-us/download/dotnet/10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)**
